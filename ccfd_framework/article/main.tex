\begin{abstract}
Credit Card Fraud Detection (CCFD) systems are vital for financial security but face the "Oracle Problem" during validation—where the correct classification of a transaction is often unknown or delayed. This paper proposes a hybrid testing framework that integrates Behavioral Modeling (via Finite State Machines), Metamorphic Testing (MT), and Genetic Algorithms (GA). We utilize the Kaggle CCFD dataset to derive realistic user behavioral profiles through clustering. These profiles inform an FSM that generates context-aware transaction sequences. We then apply Metamorphic Relations (MRs) to identify logical inconsistencies without a ground-truth oracle. Finally, a GA optimizes the test suite to maximize fault detection. Preliminary analysis suggests this hybrid approach significantly enhances the robustness of fraud detection models compared to traditional random testing.
\end{abstract}

\section{Introduction}
Credit card fraud continues to pose a significant threat to the global economy. While machine learning models for fraud detection have advanced, their validation remains a bottleneck. The core challenge is the Oracle Problem: during testing, how do we know if a system's "Normal" classification is actually a missed fraud?

This research proposes a hybrid framework to solve this. We contribute: (1) A method to infer behavioral FSMs from anonymized datasets; (2) A set of metamorphic relations tailored for financial transactions; and (3) An evolutionary strategy to find deep logic flaws.

\section{Background and Related Work}
\subsection{The Oracle Problem in CCFD}
Traditional testing relies on labels. However, in live systems, labels are delayed. Metamorphic Testing (MT) offers a solution by checking the consistency between related inputs.

\subsection{Model-Based Testing (MBT)}
MBT uses a model of the system's behavior. In this study, we use Finite State Machines (FSM) to represent the transition between different spending states of a user.

\section{Proposed Methodology}
Our framework follows a four-phase pipeline as illustrated in our implementation.

\subsection{Phase 1: Behavioral Profile Inference}
We apply K-Means clustering to the Kaggle CCFD dataset.
\begin{equation}
    J = \sum_{j=1}^{k} \sum_{i=1}^{n} \| x_{i}^{(j)} - c_{j} \|^{2}
\end{equation}
where $c_j$ is the centroid of profile $j$.

\subsection{Phase 2: FSM-Based Test Synthesis}
An FSM is defined as $M = (Q, \Sigma, \delta, q_0, F)$. Transitions $\delta$ are derived from the conditional probabilities found in the dataset.

\subsection{Phase 3: Metamorphic Testing Logic}
We define the Monotonicity Relation ($MR_1$):
\begin{definition}[MR1 - Amount Monotonicity]
For any transaction $t$, if $SUT(t) = \text{Fraud}$, then for $t'$ where $t'.amount > t.amount$ and all other features are equal, $SUT(t')$ must be $\text{Fraud}$.
\end{definition}
